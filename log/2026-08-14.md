## 18:24 — AsymKV-on-CSA sanity check via SGLang: engine fixed + first data (12 samples)

- **What:** Measured ρ_K(Δ)=E_j[cos(C_j,C_{j+Δ})] over DeepSeek-V4-Flash CSA compressed keys
  (pre-RoPE latent, d=512, T=S/4 rows) per layer, on RULER via **SGLang** on GPUs 0-3. This is
  the first experiment for AsymKV-on-CSA compatibility (adjacent-key local homogeneity).
- **How:** `transferibility/sg_asymkv_probe.py` patches sglang's `compressor_v2.py`
  (`_forward_compress_all_in_one`, right after `compress_forward`), recomputes the pre-RoPE
  RMSNorm latent, and computes per-layer ρ(Δ) on-GPU in-hook. Runs in container **`sglang-mirror`**
  (from `mirrors.sangfor.com/lmsysorg/sglang:latest-cu130` = sglang **0.5.15.post1**).
  Commands: `docker exec -e CUDA_VISIBLE_DEVICES=0,1,2,3 -e NCCL_IB_DISABLE=1 -e NCCL_SOCKET_IFNAME=lo -e NCCL_P2P_LEVEL=NVL -e SGLANG_DISTRIBUTED_INIT_METHOD_OVERRIDE=env:// -e MASTER_ADDR=127.0.0.1 -e MASTER_PORT=29501 sglang-mirror python3 .../sg_asymkv_probe.py run --per_task 2 --labels 8k,32k,64k`
- **Engine blockers found & fixed (this is why sg_capture.py never completed):**
  1. **`--shm-size`** — new containers default 64M `/dev/shm` → NCCL `ncclCommInitRank` fails
     "unhandled system error". zyh had 120G. Fix: create container with `--shm-size=120g`.
  2. **sglang 0.5.13.post1 (zyh) has a real scheduler bug** — `broadcast_pyobj` desyncs the TP
     ranks (py-spy: TP0 at size-broadcast, TP2 at data-broadcast) → spins at 150% CPU. Not
     fixable; used 0.5.15.post1 instead.
  3. **`chunked_prefill_size=-1`** → 0.5.15 MHC prewarm computes `num_tokens=-1` → "negative
     dimension". Fix: omit (default 8192).
  4. **`mem_fraction_static=0.9`** → "Not enough memory" for KV pool; **0.95** works.
  5. **`env://` dist init override** (`SGLANG_DISTRIBUTED_INIT_METHOD_OVERRIDE`) → reliable NCCL
     init; sglang's default TCPStore path was flaky.
  6. **`__main__` guard required** in the driver (0.5.15 uses mp spawn).
  7. Per-request capture reset keyed on **extend-mode transition** (req_pool_indices are reused).
- **Result:** 12 samples OK (64k niah×2, 32k niah×2, 8k all-tasks×2). T=S/4 exactly, all 21 CSA
  layers, reproducible (max |Δρ1| across samples < 0.023). Layer-mean ρ1: 8k 0.54, 32k 0.49,
  64k 0.50. **ρ1>ρ2 holds but ρ4 is anomalously high (≥ρ2; >ρ1 for niah) — a period-4 peak.** vt
  shows the cleanest monotone decay (ρ1≈0.57-0.88), niah does NOT (ρ4 peak). Shared-KV note:
  ρ_V≡ρ_K by construction.
- **Blockers:** full 64k RULER prompts (S=58-70k) exceed the KV pool on 4 GPUs (weights load as
  bf16 ~73GB/card at mem_fraction 0.95; auto max_total ≈52k). Only niah (S~50k) fits. The other
  tasks' 64k samples are truncated by the scheduler → MISSING.
- **Artifacts:** `transferibility/ckpt_sglang/*.json` (12), `transferibility/out_sglang/asymkv_csa_{8k,32k,64k}.{md,json}` + `asymkv_csa_summary.md` + `asymkv_figs/*.png`.
