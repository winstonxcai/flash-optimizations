# LongSWE replay collections

Author: Winston Cai.

Group collections by model: `ds4-flash-0731/`, `ds41-flash-1017/`, and
`glm53-flash/`. Name each collection
`<workload-or-concurrency>-<comparison>-<repetitions>-<date>`; include hardware
when needed to distinguish similar collections. Omit repetition counts for
incomplete studies when they would imply completed measurements.

Each collection records its workload, source identities, original run IDs,
validity and limitations. Preserve original receipts and paths as provenance.
Migration of older collections into these model folders is in progress.
